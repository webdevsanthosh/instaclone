# InstaLite — Basic Instagram Clone

A beginner-friendly social media UI made with **HTML, CSS, and vanilla JavaScript**.

## Run the project
1. Download and extract `insta_clone_basic.zip`.
2. Open the `insta_clone_basic` folder.
3. Double-click `index.html` to open it in Chrome, Edge, or Firefox.

For the best development experience, open the folder in Visual Studio Code and use the **Live Server** extension.

## Included features
- Responsive Instagram-inspired layout
- Story viewer with next-story navigation
- Reels feed with video playback, upload, likes, and comments
- Search posts by username, caption, or location
- Explore post grid and personal profile page
- Like/unlike posts, comment, and double-click to like
- Save and unsave posts in a Saved view
- Local demo conversations with suggested accounts
- Activity list for your likes, comments, and posts
- Create a post from a local image or image URL
- Follow suggested accounts
- Edit username, display name, and bio
- Saves posts, profile details, follows, messages, reels, and activity in browser storage (`localStorage` and `IndexedDB` for uploaded videos)

## Important limitations
This is a **front-end demo only**. It does not have real accounts, secure login, a server, or multi-device sync. Messages, reels, and activity are local demo interactions and are not delivered to other people. Uploaded reel videos are stored in the current browser; the demo allows videos up to 100 MB. Do not use real passwords or sensitive personal information. A production version needs a backend and authentication.

## Customize
- Edit sample posts and stories in `script.js`.
- Change colors, spacing, and layout in `style.css`.
- Change page content and structure in `index.html`.
